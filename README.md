# 烛烬 · 读书摘录

马洛伊·山多尔（Sándor Márai）《烛烬》的二十则摘录与评注，做成一个单页阅读网站。

在线阅读：https://zxc11234.github.io/zhujin-reading-notes/

## 关于设计

整本书是一夜之间的一场谈话，烛火烧尽即天明。所以页面右侧那根蜡烛的高度就是阅读进度，读到底它烧到底座；右上角可以从「夜」切到「黎明」，因为小说正是在烛尽天明时结束的。

二十则摘录按主题编为五卷：接受、友谊、激情、命运、不可言说。引文按长短分三档字号，评注向右让出一段、以一道琥珀细线区隔。

## 技术

单个 `index.html`，无构建、无依赖、无外部请求。

- 蜡烛燃烧用 CSS `animation-timeline: scroll()`，不监听 scroll 事件；浏览器不支持时静止降级
- 入场动效走 IntersectionObserver，`prefers-reduced-motion` 下全部关闭
- 中文正文使用系统宋体栈（Noto Serif SC / 思源宋体 / 宋体-简），不加载网络字体
- 夜／黎明两套配色共用同一强调色，选择存在 localStorage

本地打开：

```bash
open index.html
```
